# Home Media Server
## Back End
* Spring boot microservices that make up a video media service.
* Make the microservices dockerizable
* Allow users to search and add new movies and series to the server. 
  * This must automatically find and download the torrent then organise the files.
  * Try to virus scan the torrent folder and validate the files safety.

## Front End
* Build a front end with vue.js framework
* Front end to display all the media.
  * Has search functionality
  * Has high performance stream window for viewing the media
  * Includes closed caption controls
